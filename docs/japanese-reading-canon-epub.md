# Japanese Reading Canon — 50 EPUBs

A practical **elementary → college** reading ladder for Japanese study in EPUB format.

- This is **not an official MEXT mandatory reading list**; Japan does not have one fixed nationwide list of 50 books.
- The progression is a curated school-like canon using works commonly taught, culturally canonical, or useful as a bridge into native literature.
- All links below are direct `.epub` downloads generated from **Aozora Bunko** texts by **aohelp.club**.
- Verified: **2026-10-09**
- For Echo: these are reflowable text EPUBs with ruby support where present, much better suited to extraction than scanned manga/PDFs.

## Notes for Echo

A useful order is not necessarily strict chronological school grade. The main goal is to increase:

1. sentence length,
2. literary vocabulary,
3. kanji density,
4. older grammar/register,
5. total book length.

For Echo, consider storing per-book metadata such as:

```json
{
  "title": "走れメロス",
  "author": "太宰治",
  "stage": "upper-elementary-middle",
  "source": "Aozora Bunko via aohelp.club",
  "epub": "https://aohelp.club/static/epub/1567_ruby_4948.epub"
}
```
