## What changed in the app

1. **Mora anchors are v5.** The owner took five AnchorAudit replacements:
   よ 鎧 armour, れ レモン lemon, ち 地図 map, ん 判子 seal stamp, こ 駒 spinning top.
   そ keeps ソファ (蕎麦 declined). Fused ょ sounds follow (みょ = 水＋鎧), and so
   do voiced sounds (ご = 巨大な駒, ぢ = 巨大な地図).
2. **The pictures are the owner's new 512px set**, shipped at 128px, with や, め
   and つ redrawn (no frame; one plain desk; め and つ drawn larger). The dark set
   is the same drawing with ink `#F2EEE3` and seal `#E0614B`.
3. **Write it again** is a real action now. The owner chose: a fresh wording
   **replaces** the sentence (only the new one is practised). It is a row in the
   sentence's ⋯ menu, after Edit: 新 Write it again — "Echo says the same thing a
   fresh way; it replaces this one". Edit, or correct with Echo now carries your
   pencil.
4. **Echo's note on a word shows two parts**, as WordNote drew: "Echo's note — how
   to say it", then "Echo's note — the kanji". They are one note text split at the
   labels Echo writes.
5. **Echo's notes** can rewrite every note still written with a v4 anchor: a box
   above the list, "N notes still use older anchors", with "Rewrite them with the
   new anchors". Notes the learner wrote are never touched.
