# Mora anchor pictures

`anchors/` (light) and `anchors-dark/` (dark) hold one drawn picture per mora
anchor (MORA_MNEMONICS v5; `mora-pictures.js` maps kana to file).

- **Author:** drawn by the Echo project owner (KakkoiDev), as the owner's own
  set (see CLAUDE.md, "Mora pictures are the owner's drawn set"). The light set
  is the owner's 512 px masters exported at 128 px; the dark set is the same
  drawing with ink → `#F2EEE3` and seal → `#E0614B`.
- **Licence:** not yet stated by the owner. Until it is, treat the pictures as
  all rights reserved by the owner: do not reuse them outside Echo.

The owner should replace the licence line with the licence they choose.
